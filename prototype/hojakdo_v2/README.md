# 호작도 V2 통합 시뮬레이션

큰 까치와 작은 까치가 43분 절대 타임라인에서 번갈아 등장하는 V2 시각 검증용 프로토타입이다. V1은 비교와 회귀 확인을 위해 그대로 보존한다.

## 이번 단계에서 검증하는 것

- 첫 2분 `HIDDEN`, 자정에 끊기지 않는 절대 시간 계산
- 큰 까치·작은 까치의 엄격한 교대와 한 장면 한 마리 원칙
- 하루 평균 약 6회의 2사분면 바늘 착석
- 분침 직접, 시침→분침 환승, 매화 걷기 경로
- 큰 까치의 느린 고개 동작·필요 시 한 번의 방향 전환·접은 날개 점프 퇴장
- 작은 까치의 세 차례 상체 행동·2/3 장면 귀 쪼기·두 번 날갯짓 퇴장
- 호랑이의 머리 선행, 눈동자 후행, 작은 반동과 중립 복귀
- AOD에서 까치와 모든 반응을 숨기는 계산 결과

작은 까치는 현재 원본 레이어에 붙어 있는 가지 조각을 렌더 시 임시 마스킹한 시각 초안을 사용한다. 모션과 좌표를 승인한 뒤 최종 AGIF 제작 전에 깨끗한 작은 까치 마스터를 별도로 분리해야 한다.

## 실행

저장소 루트에서 다음을 실행한다.

```bash
python -m unittest prototype.hojakdo_v2.test_scene_calculator
python -m prototype.hojakdo_v2.render_prototype
```

결과물은 `prototype/hojakdo_v2/output`에 생성된다. 이 결과는 WFF나 AGIF에 연결된 최종 빌드가 아니라, 승인 전 타이밍·구도·성격 차이를 빠르게 확인하기 위한 통합 시뮬레이션이다.
