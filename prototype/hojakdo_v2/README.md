# 호작도 V3.1 통합 시뮬레이션

큰 까치와 작은 까치가 43분 절대 타임라인에서 번갈아 등장하고, 배터리 잔량에 따라 매화가 다섯 단계로 바뀌는 V3.1 시각 검증용 프로토타입이다. 이전 V2.3 출력은 비교와 회귀 확인을 위해 그대로 보존한다.

> **V3.1 완료 규칙 (2026-07-15):** 작은 까치 퇴장은 승인된 오른쪽 고정 비행 한 장으로 교체하고, 날갯짓 없이 까치 전체를 이동한다. 화면 가운데 디지털 시각·요일과 배터리 표시는 그대로 유지한다.

## 이번 단계에서 검증하는 것

- 첫 2분 `HIDDEN`, 자정에 끊기지 않는 절대 시간 계산
- 큰 까치·작은 까치의 엄격한 교대와 한 장면 한 마리 원칙
- 하루 평균 약 6회의 2사분면 바늘 착석
- 분침 직접, 시침→분침 환승, 매화 걷기 경로
- 큰 까치의 오른쪽 등장·발 기준점 고정 0.85728배 렌더링·뒤보기 후 오른쪽 복귀·접은 날개 점프 퇴장
- 작은 까치의 세 차례 상체 행동·2/3 장면 귀 쪼기·고정 스프라이트의 날갯짓 0회 퇴장
- 깨끗한 작은 까치 마스터, 실제 수평 이동량 기반 진행 방향, 호랑이 착지 뒤 홉 전환
- 호랑이 턱·목 알파 복원과 반응 중 연결부 유지
- 호랑이의 머리 선행, 눈동자 후행, 작은 반동과 중립 복귀
- 호랑이 94% 그룹 축소와 작은 까치의 시침·분침별 실제 끝점 접촉
- 배터리 5단계 매화 정적 교체, 기존 숫자 표시 유지, 전환 애니메이션 없음
- AOD에서 까치와 모든 반응은 숨기고 현재 매화 단계는 낮은 밝기로 유지

작은 까치는 가지와 붉은 노리개를 제거한 착석 마스터를 사용한다. 퇴장에서는 138×107 고정 비행 스프라이트 한 장으로 교체하고, 회전·크기 변화 없이 `smoothstep` 48px 포물선을 따라 화면 오른쪽 밖까지 이동한다.

## 실행

저장소 루트에서 다음을 실행한다.

```bash
python -m unittest discover -s prototype -p 'test_*.py'
python -m prototype.hojakdo_v2.render_prototype
python -m prototype.hojakdo_v2.build_v23_assets
python -m prototype.hojakdo_v2.render_v23_preview
python -m prototype.hojakdo_v2.build_v31_assets
python -m prototype.hojakdo_v2.render_v31_preview
```

결과물은 `prototype/hojakdo_v2/output`에 생성된다. 이 결과는 WFF나 AGIF에 연결된 최종 빌드가 아니라, 승인 전 타이밍·구도·성격 차이를 빠르게 확인하기 위한 통합 시뮬레이션이다.

현재 전체 회귀 테스트는 총 39개다. V3.1 검사는 승인 원본 해시, 빌드 재현성, 투명 RGB 정규화, 고정 픽셀·기준점·크기·회전, 날갯짓 0회, `smoothstep` 포물선, 완전 화면 밖 퇴장, 매화 만개와 중앙 표시 보존을 포함한다.
