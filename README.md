# Hojakdo Watch Face

갤럭시 워치용 한국 민화 **호작도(鵲虎圖)** 콘셉트 워치페이스입니다.

> 손목 위에서 살아 움직이는 호작도 한 점.

애니메이션과 장면 구현의 최상위 기준은 [`docs/animation-blueprint.md`](docs/animation-blueprint.md)에서 관리합니다.

소나무 가지를 시침과 분침으로 사용하고, 큰 까치와 작은 까치가 시간과 바늘의 위치에 따라 그림 속을 이동합니다. 움직임은 매끄러운 캐릭터 애니메이션보다 **피영극처럼 조금 뻣뻣하고 절제된 동작**을 지향합니다.

## 현재 움직임 MVP

- 시침 가지: 1분마다 약 `0.5°` 이동
- 분침 가지: 1분마다 `6°` 이동
- 이동 시간: 약 `0.35초`
- 까치: 가지를 따라 이동하면서 역회전하여 항상 수직 유지
- 12시·6시 경계에서 좌우 방향 전환
- 호랑이 머리와 눈동자는 현재 고정

현재 프로젝트는 `assets/layers/mvp`의 원본 PNG를 빌드 시 워치페이스 리소스로 복사합니다. 미러 버전 까치 PNG도 빌드 과정에서 자동 생성됩니다.

## Android Studio 실행

1. 저장소를 최신 상태로 받습니다.
2. 저장소 루트 폴더를 Android Studio에서 엽니다.
3. Gradle Sync를 실행합니다.
4. Wear OS API 33 이상 에뮬레이터 또는 기기를 선택합니다.
5. `watchface` 모듈을 실행합니다.

## 까치 행동 규칙

### 기본 원칙

```text
가지 = 항상 시계 바늘
까치 = 시간에 따라 이동하는 등장인물
```

큰 까치와 작은 까치는 번갈아 출연합니다. 특정 까치를 시침 또는 분침 전용으로 고정하지 않고, 현재 화면에서 자연스럽게 앉을 수 있는 위치를 선택합니다.

### 장면 진행

애니메이션은 사용자가 화면을 켤 때 처음부터 시작하지 않습니다.

```text
현재 시각
→ 현재 장면과 진행 단계 계산
→ 해당 위치와 동작 표시
```

현재 장면이 진행되는 동안에는 더 좋은 후보가 생겨도 행동을 바꾸지 않습니다. 저장된 런타임 상태 대신 날짜와 시각으로 현재 장면과 다음 장면의 결정값을 함께 계산합니다.

```text
현재 장면 진행
→ 다음 장면 결정값 선계산
→ 현재 장면 종료
→ 계산된 다음 장면 표시
→ 그다음 장면 결정값 계산
```

같은 시각에 화면을 다시 열어도 결과가 바뀌지 않도록 날짜와 시간 구간을 바탕으로 고정 난수를 사용합니다.

### 착석 우선순위

1. 2사분면에 자연스럽게 앉을 수 있는 바늘
2. 호랑이 머리와 가까워지는 바늘
3. 적합한 바늘이 없으면 매화 출입 경로

```text
분침이 2사분면에 있음 → 분침 우선
시침만 2사분면에 있음 → 시침 선택
둘 다 가능함 → 자연스러움 점수 비교
```

까치가 시침에 앉더라도 한 시간 동안 고정되지 않습니다. 바늘을 타고 이동하다가 호랑이 머리에 가까워지면 하차합니다.

### 바늘 탑승 경로

```text
소나무에서 등장
→ 2사분면 바늘로 날아감
→ 바늘에 착석
→ 바늘을 타고 이동
→ 4시 30분~5시 30분 부근에서 호랑이 머리로 하차
→ 머리 위에 머묾
→ 오른쪽으로 퇴장
```

하차 조건은 까치의 발 위치와 호랑이 머리 착석점 사이의 거리, 접근 방향, 화면 구도를 함께 사용합니다.

### 바늘이 부자연스러울 때

매화는 착석지가 아니라 출입구로 사용합니다.

```text
앉기 좋은 바늘 없음
→ 매화 뒤에서 등장
→ 호랑이 방향으로 걸어감
→ 1분에 한 걸음
→ 호랑이 머리 근처 도착
→ 머리 위로 올라감
```

걷는 도중 좋은 바늘이 생겨도 현재 걷기 장면은 끝까지 진행합니다.

### 교대와 퇴장

```text
큰 까치
→ 오른쪽 퇴장
→ 작은 까치 등장
→ 오른쪽 퇴장
→ 큰 까치 등장
```

기존 까치가 호랑이 머리에 있을 때 다음 까치의 출연 시간이 오면, 기존 까치는 오른쪽으로 날아가 사라집니다.

## 상태 목록

| 상태 | 설명 |
|---|---|
| `HIDDEN` | 다음 출연을 기다림 |
| `SPAWN_PINE` | 소나무에서 등장 |
| `FLY_PINE_TO_HAND` | 소나무에서 2사분면 바늘로 비행 |
| `LAND_ON_HAND` | 바늘에 착지하는 짧은 전환 |
| `PERCH_HAND` | 착지 후 바늘 위에 정지 |
| `RIDE_HAND` | 바늘을 타고 이동 |
| `SPAWN_PLUM` | 매화 뒤에서 등장 |
| `WALK_FROM_PLUM` | 1분에 한 걸음씩 이동 |
| `LAND_ON_TIGER` | 호랑이 머리로 이동 |
| `PERCH_TIGER` | 호랑이 머리 위에 머묾 |
| `FLY_OUT_RIGHT` | 오른쪽으로 퇴장 |

## 애니메이션 원칙

복잡한 위치와 장면 선택은 WFF 표현식·조건식·Transform이 담당하고, 짧은 몸동작은 AGIF로 표현합니다.

```text
WFF 표현식/조건식 → 위치, 경로, 상태, 다음 장면
짧은 AGIF → 한 걸음, 착지, 날갯짓, 호랑이 반응
```

필수 동작 후보:

- 소나무에서 바늘로 날아가기
- 바늘 위 착지
- 매화에서 한 걸음
- 호랑이 머리로 점프
- 오른쪽 퇴장

큰 까치와 작은 까치 각각 5개, 호랑이 반응 1개로 총 11개 움직임 자산을 기준으로 합니다.
