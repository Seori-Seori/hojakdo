# Hojakdo Watch Face

갤럭시 워치용 한국 민화 **호작도(鵲虎圖)** 콘셉트 워치페이스다.

> 손목 위에서 살아 움직이는 호작도 한 점.

소나무 가지를 시침과 분침으로 사용하고, 큰 까치와 작은 까치가 절대 시간에 맞춰 그림 속을 이동한다. 움직임은 부드러운 캐릭터 애니메이션보다 피영극처럼 빠르게 움직이고 오래 멈추는 절제된 리듬을 지향한다.

애니메이션과 장면 구현의 최상위 기준은 [`docs/animation-blueprint.md`](docs/animation-blueprint.md), 자산 분리 상태는 [`docs/asset-extraction-plan.md`](docs/asset-extraction-plan.md)에서 관리한다.

## 현재 단계

> **V2.3 매화 배터리 5단계 완료 / AGIF·WFF 연결 전**

V1·V2·V2.1 결과는 회귀 비교용으로 보존했다. V2.2에서는 호랑이와 큰 까치의 비중, 작은 까치의 양쪽 바늘 착지점을 보정했다. V2.3에서는 기존 숫자 배터리 표시를 유지하면서 배터리 잔량에 따라 매화가 다섯 단계로 피도록 정적 레이어를 추가했다.

현재 완료된 범위:

- 43분 절대 사이클과 첫 2분 `HIDDEN`
- 큰 까치·작은 까치의 엄격한 교대와 한 장면 한 마리 원칙
- 분침 직접, 시침→분침 환승, 매화 걷기 경로
- 실제 착지 완료 시각 기준 하루 평균 약 6회의 2사분면 바늘 착석
- 365일 검증 범위에서 하루 4~8회, 평균 5.997회
- 큰 까치의 오른쪽 등장, 발 기준점 고정 최종 0.85728배 렌더링, 느린 고개 동작, 뒤보기·복귀 방향 동작, 접은 날개 점프 퇴장
- 작은 까치의 고개 살피기·매화 보기·다음 목표 확인, 3회 중 2회의 귀 두 번 쪼기, 어깨에 연결된 피영극식 날개로 정확히 두 번 날갯짓
- 모든 이동 구간에서 실제 수평 이동량에 맞춘 좌우 방향, 호랑이 착지 뒤 작은 홉 전환
- 작은 까치가 시침·분침의 서로 다른 실제 끝점에 발과 가지를 약 2px 겹쳐 착지
- 호랑이 몸통·머리·눈동자를 하나의 그룹으로 묶어 94%로 축소하고 턱·목 알파 복원 유지
- 배터리 `0~15 / 16~35 / 36~55 / 56~80 / 81~100%`에 대응하는 매화 5단계 정적 교체
- 배터리 아이콘·숫자 퍼센트 유지, 피어나는 전환 애니메이션 없음
- 호랑이 머리 선행, 눈동자 후행, 작은 반동과 중립 복귀
- AOD에서 까치와 모든 세부 애니메이션은 숨기고 현재 매화 단계는 낮은 밝기로 유지
- 결정성·교대·경로 고정·자정 연속성·빈도·AOD·쪼기·날갯짓·배터리 경계·자산 메모리 자동 테스트
- V1 7개 + 통합 V2 계열 23개 + V2.3 6개, 총 36개 자동 테스트 통과

이 단계는 **시각 검증용 정적 시뮬레이션**이다. 아직 17개 AGIF 제작, 실제 WFF 연결, 에뮬레이터 또는 실기기 구현 완료를 뜻하지 않는다.

## 승인된 핵심 규칙

### 절대 시간과 교대

```text
43분 사이클
→ 첫 2분 HIDDEN
→ 큰 까치 또는 작은 까치 한 마리
→ 경로 완료
→ 오른쪽 화면 밖까지 퇴장
→ 다음 사이클에서 반대 까치
```

- 자정에 사이클을 초기화하지 않는다.
- 사이클 시작 때 경로와 바늘을 결정하고 끝까지 바꾸지 않는다.
- 화면을 다시 켜도 같은 시각에는 같은 까치·경로·거시 위치를 복원한다.
- `EXIT_RIGHT`는 공통 논리 상태이며 큰 까치는 점프, 작은 까치는 두 번 날갯짓으로 표현한다.

### 경로

```text
분침 직접: 소나무 → 분침 → 호랑이 → 오른쪽 퇴장
시침 환승: 소나무 → 시침 → 분침 환승 → 호랑이 → 오른쪽 퇴장
매화 경로: 매화 → 한 칸씩 이동 → 호랑이 → 오른쪽 퇴장
```

큰 까치와 작은 까치를 특정 바늘 전용으로 고정하지 않는다. 큰 까치는 안쪽의 두꺼운 착석점과 시침에 조금 더 어울리고, 작은 까치는 바깥쪽의 얇은 착석점과 분침 직접 경로에 조금 더 어울리도록 가중치와 좌표만 다르게 둔다.

### 세부 행동

- 큰 까치: 긴 체류 중 느린 고개 동작 1회, 구도상 필요할 때 상체 뒤보기 최대 1회
- 작은 까치: 긴 체류의 약 25%·50%·75% 지점에 최대 3개의 상체 행동
- 이동 중 몸 방향은 실제 수평 이동 방향을 따르고, 작은 까치는 호랑이 착지 뒤 귀 쪽으로 홉 전환
- 작은 까치가 호랑이 위에 앉는 장면 3회 중 2회에는 귀를 빠르게 두 번 쪼음
- 추가 행동 중 발 기준점은 고정하고 상체만 움직임
- 한 사이클의 호랑이 반응은 정확히 1회이며, 귀 쪼기 장면에서는 쪼기가 유일한 반응 원인

### AOD

- 모든 AGIF와 까치를 숨김
- 호랑이 세부 반응 레이어를 숨김
- 현재 배터리 구간의 매화 정적 단계는 낮은 밝기로 유지
- 시간 표시와 필요한 최소 윤곽만 유지

## 자산 상태

- 큰 까치: 승인된 깨끗한 기반 마스터 사용
- 작은 까치: 가지·붉은 노리개가 없는 V2.1 투명 기반 마스터 사용
- 호랑이: 턱·목 알파를 복원한 V2.2 머리와 94% 눈동자 분리 레이어 사용
- 매화: 빈 가지가 포함된 V2.3 기본 배경 1장과 누적 꽃 레이어 5단계 사용

## Android Studio 실행

1. 저장소 루트 폴더를 Android Studio에서 연다.
2. Gradle Sync를 실행한다.
3. Wear OS API 33 이상 에뮬레이터 또는 기기를 선택한다.
4. `watchface` 모듈을 실행한다.

현재 `watchface`는 기존 바늘 MVP다. V2.3 승인 뒤 17개 AGIF와 새 무상태 결정식을 연결하는 단계가 남아 있다.
