# Hojakdo Watch Face

갤럭시 워치용 한국 민화 **호작도(鵲虎圖)** 콘셉트 워치페이스입니다.

> 손목 위에서 살아 움직이는 호작도 한 점.

애니메이션과 장면 구현의 최상위 기준은 [`docs/animation-blueprint.md`](docs/animation-blueprint.md)에서 관리합니다.

소나무 가지를 시침과 분침으로 사용하고, 큰 까치와 작은 까치가 시간과 바늘의 위치에 따라 그림 속을 이동합니다. 움직임은 매끄러운 캐릭터 애니메이션보다 **피영극처럼 조금 뻣뻣하고 절제된 동작**을 지향합니다.

## 현재 움직임 MVP

- 시침 가지: 1분마다 약 `0.5°` 이동
- 분침 가지: 1분마다 `6°` 이동
- 이동 시간: 약 `0.35초`
- 까치: 가지를 따라 이동하면서 역회전하여 항상 수직 유지
- 12시·6시 경계에서 좌우 방향 전환
- 호랑이 머리와 눈동자는 현재 고정

현재 프로젝트는 `assets/layers/mvp`의 원본 PNG를 빌드 시 워치페이스 리소스로 복사합니다. 미러 버전 까치 PNG도 빌드 과정에서 자동 생성됩니다.

## 큰 까치 전용 V1 계획

> 상태: **첫 정적 프로토타입 제작 완료 / WFF 연결 전**
>
> 목표: 큰 까치 한 마리로 전체 장면 계산·경로·환승·호랑이 반응·퇴장까지 먼저 완성하고, 빠른 시뮬레이션 GIF로 숫자를 튜닝한 뒤 WFF에 연결합니다.

현재 승인된 `magpie_large_base_master.png`는 V1 시안 자산입니다. 아직 실제 워치페이스의 장면 계산이나 애니메이션에는 연결되지 않았습니다.

### V1 범위

- 큰 까치만 반복 출연
- 사이클 시작 시 바늘과 경로를 한 번 결정하고 종료까지 고정
- 분침 경로, 시침→분침 환승 경로, 매화 걷기 경로 지원
- 사이클당 호랑이 반응 1회
- 호랑이 머리 체류 후 항상 오른쪽으로 퇴장
- 현재 시각 기반 장면 복원
- 자정에도 진행 중인 사이클을 초기화하지 않고 절대 타임라인으로 연속 계산
- AOD에서는 까치와 모든 애니메이션 숨김
- 작은 까치는 큰 까치 V1 검증 뒤 추가

### 한 사이클

한 사이클은 까치 한 마리의 `HIDDEN`부터 오른쪽 퇴장까지를 뜻합니다.

```text
첫 5% HIDDEN
→ 소나무 또는 매화에서 등장
→ 선택된 경로 진행
→ 움직임 중 호랑이 반응 1회
→ 마지막 5% 호랑이 머리 체류
→ 오른쪽 고정 퇴장
→ 다음 큰 까치 사이클
```

사이클 길이, 점수 가중치, 각도 허용 범위, 최소 시침 탑승시간은 V1 튜닝값입니다. 구현 로직에 흩어 쓰지 않고 하나의 장면 설정 파일에서 관리합니다.

### 등장 위치와 퇴장

- 소나무 경로: 화면 왼쪽 소나무 몸통 중간의 가지와 솔잎 뒤에서 등장
- 매화 경로: 화면 왼쪽 아래 매화나무 뒤에서 등장해 호랑이 방향으로 걸음
- 퇴장 경로: 호랑이 머리에서 몸을 낮춘 뒤 항상 화면 오른쪽 밖으로 비행
- 장거리 좌표 이동은 WFF Transform, 짧은 몸동작은 AGIF가 담당

### 바늘 선택

사이클 시작 시 현재 각도와 착지 예상 각도를 함께 평가합니다.

```text
한 바늘이 확실히 우세함 → 해당 바늘
두 바늘 점수가 비슷함   → 날짜·사이클 기반 고정 난수
둘 다 부적합함           → 매화 걷기 경로
```

초기 점수는 2사분면 각도, 소나무 접근성, 화면 잘림, 호랑이 접근 방향, 사이클 안에 경로를 완료할 수 있는지를 사용합니다. 선택 결과는 장면 중간에 다시 평가하지 않습니다.

환승과 호랑이 도착이 현재 사이클 안에 들어오지 않는 시침은 처음부터 후보에서 제외합니다. 선택된 뒤 중간 퇴장이나 강제 경로 변경으로 시간을 맞추지 않습니다.

### 분침 직접 경로

```text
소나무 등장
→ 분침 비행·착지
→ 분침 탑승
→ 호랑이 접근
→ 호랑이 머리 착석
```

### 시침→분침 환승 경로

시침이 선택되면 호랑이까지 5~8시간을 그대로 기다리지 않고, 분침이 따라와 만나는 시점에 환승합니다.

```text
소나무 등장
→ 시침 비행·착지
→ 시침 탑승
→ 첫 번째 자연스러운 시침·분침 만남
→ 짧은 피영극식 홉으로 분침 환승
→ 분침 탑승
→ 호랑이 머리 착석
```

- 시침과 분침의 만남은 각도 차이가 가장 작은 분으로 계산
- 착지 직후 너무 빨리 만나는 경우 다음 만남 사용
- 실제 두 발 기준점의 거리가 자연스러운지도 함께 검증
- 환승 시점은 사이클 시작 때 계산하고 중간에 변경하지 않음
- 시침 장면의 하루 횟수 제한은 두지 않고, 사이클 안에 환승 경로를 마칠 수 있는지를 후보 조건으로 사용
- V1에서는 기존 짧은 홉 자세를 재사용하고, 어색할 때만 전용 `hop_hand_to_hand` 자산 추가

### 호랑이 반응

- 까치가 움직이는 후보 순간 중 하나를 고정 난수로 선택
- 한 사이클에 정확히 한 번
- 호랑이가 까치가 있는 왼쪽 위 방향으로 고개를 조금 움직였다가 복귀
- 고정 반응 방향이 자연스럽도록 까치가 호랑이의 왼쪽 또는 왼쪽 위에 있는 움직임만 반응 후보로 사용
- 피영극처럼 빠르게 움직이고 정확히 멈춘 뒤 작은 반동
- 퇴장 동작은 호랑이 반응 후보에서 제외
- 화면 재점등 시 짧은 반응 AGIF가 다시 재생될 수 있으나 거시 상태와 위치는 바뀌지 않음

### 애니메이션 리듬

```text
빠른 동작 2~3프레임
→ 정지 2프레임
→ 작은 반동 1프레임
→ 마지막 자세 2~3프레임
```

- 약 6~8fps
- 대부분 6~8프레임
- 부드러운 보간과 반복 대기 애니메이션 금지
- 위치 이동보다 정지 시간이 길어야 함

### 시뮬레이션 검증

WFF 연결 전에 같은 설정과 상태 계산기로 다음 GIF를 생성합니다.

1. 24시간 전체 흐름을 약 20~30초로 압축한 GIF
2. 한 사이클을 분 단위로 확인하는 상세 GIF

디버그 GIF에는 현재 시각, 상태, 선택 경로, 선택 바늘, 각 바늘 점수, 사이클 진행률, 호랑이 반응 시점과 다음 상태를 표시합니다. 좌표와 숫자는 GIF를 반복 확인하며 수정합니다.

### 첫 정적 프로토타입

승인된 규칙을 실제 WFF에 연결하기 전 단계로 다음 프로토타입을 작성했습니다.

- 하나의 `config.json`에서 1차 사이클·점수·좌표 관리
- 현재 날짜와 시각만으로 장면을 복원하는 무상태 계산기
- 분침 직접, 시침→분침 환승, 매화 걷기 경로
- 사이클당 호랑이 반응 1회와 오른쪽 퇴장
- 결정성·경로 고정·자정 연속성·렌더링 슬롯 자동 테스트
- 2026-07-14 하루 24시간 압축 GIF와 시침 환승 상세 GIF

결과물과 실행 방법은 [`prototype/large_magpie_v1`](prototype/large_magpie_v1)에서 확인합니다. 현재 결과는 **정적 시뮬레이션 프로토타입**이며 AGIF 제작, 실제 WFF 연결, 에뮬레이터 구현 완료를 뜻하지 않습니다.

## 까치 행동 규칙

### 기본 원칙

```text
가지 = 항상 시계 바늘
까치 = 시간에 따라 이동하는 등장인물
```

큰 까치와 작은 까치는 번갈아 출연합니다. 특정 까치를 시침 또는 분침 전용으로 고정하지 않고, 현재 화면에서 자연스럽게 앉을 수 있는 위치를 선택합니다.

### 장면 진행

애니메이션은 사용자가 화면을 켤 때 처음부터 시작하지 않습니다.

```text
현재 시각
→ 현재 장면과 진행 단계 계산
→ 해당 위치와 동작 표시
```

현재 장면이 진행되는 동안에는 더 좋은 후보가 생겨도 행동을 바꾸지 않습니다. 저장된 런타임 상태 대신 날짜와 시각으로 현재 장면과 다음 장면의 결정값을 함께 계산합니다.

```text
현재 장면 진행
→ 다음 장면 결정값 선계산
→ 현재 장면 종료
→ 계산된 다음 장면 표시
→ 그다음 장면 결정값 계산
```

같은 시각에 화면을 다시 열어도 결과가 바뀌지 않도록 날짜와 시간 구간을 바탕으로 고정 난수를 사용합니다.

### 착석 우선순위

1. 2사분면에 자연스럽게 앉을 수 있는 바늘
2. 호랑이 머리와 가까워지는 바늘
3. 적합한 바늘이 없으면 매화 출입 경로

```text
분침만 적합함 → 분침 직접 경로
시침만 적합함 → 시침→분침 환승 경로
둘 다 적합함 → 자연스러움 점수 비교, 비슷하면 고정 난수
둘 다 부적합함 → 매화 걷기 경로
```

까치가 분침에 앉으면 호랑이 접근 시점까지 분침을 탑니다. 시침에 앉으면 분침과의 만남을 기다린 뒤 짧게 환승하고, 분침을 타고 호랑이로 이동합니다.

### 바늘 탑승 경로

```text
분침 경로: 소나무 → 분침 → 호랑이 → 오른쪽 퇴장
시침 경로: 소나무 → 시침 → 분침과 만남 → 분침 환승 → 호랑이 → 오른쪽 퇴장
```

하차 조건은 까치의 발 위치와 호랑이 머리 착석점 사이의 거리, 접근 방향, 화면 구도를 함께 사용합니다.

### 바늘이 부자연스러울 때

매화는 착석지가 아니라 출입구로 사용합니다.

```text
앉기 좋은 바늘 없음
→ 매화 뒤에서 등장
→ 호랑이 방향으로 걸어감
→ 1분에 한 걸음
→ 호랑이 머리 근처 도착
→ 머리 위로 올라감
```

걷는 도중 좋은 바늘이 생겨도 현재 걷기 장면은 끝까지 진행합니다.

### 교대와 퇴장

```text
큰 까치
→ 오른쪽 퇴장
→ 작은 까치 등장
→ 오른쪽 퇴장
→ 큰 까치 등장
```

기존 까치가 호랑이 머리에 있을 때 다음 까치의 출연 시간이 오면, 기존 까치는 오른쪽으로 날아가 사라집니다.

큰 까치 전용 V1에서는 작은 까치 차례를 아직 사용하지 않고, 퇴장과 숨김 구간 뒤 큰 까치가 다시 등장합니다.

## 애니메이션 원칙

복잡한 위치와 장면 선택은 WFF 표현식·조건식·Transform이 담당하고, 짧은 몸동작은 AGIF로 표현합니다.

```text
WFF 표현식/조건식 → 위치, 경로, 상태, 다음 장면
짧은 AGIF → 한 걸음, 착지, 날갯짓, 호랑이 반응
```

필수 동작 후보:

- 소나무에서 바늘로 날아가기
- 바늘 위 착지
- 시침에서 분침으로 짧게 환승
- 매화에서 한 걸음
- 호랑이 머리로 점프
- 오른쪽 퇴장

기본 기준은 큰 까치와 작은 까치 각각 5개, 호랑이 반응 1개로 총 11개입니다. 시침→분침 환승은 초기에는 기존 홉 자세를 재사용하고, 실제 화면에서 부자연스러울 때 큰·작은 까치 전용 환승 자산을 추가합니다.
